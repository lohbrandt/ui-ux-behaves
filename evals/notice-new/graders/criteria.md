A successful response meets all of these:

1. No toast per notification: the arrival updates a count on the bell instead.
2. The count is part of the bell's accessible name (for example "Notifications, 3 unread"), not only a visual badge or colour.
3. Screen readers get one polite announcement per arrival (or one combined announcement for several, e.g. "1 new notification"), never assertive and never stealing focus.
4. Colour (red bell) is not the only signal; a number or text carries the meaning.
5. The details are read where the person chooses to look (the bell's panel or the full list), not pushed into the workflow.

Score 1 only if all five points are clearly present and none is contradicted.
