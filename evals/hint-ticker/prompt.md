We want to make the dismissed hints and suggestions of a page more discoverable. Idea from the
team: next to the information "(i)" button in the page header, show a one-line rotating ticker
that cycles through the page's hints every 3 seconds, on every screen size, and announce each new
text to screen readers so blind users don't miss anything.

Review this idea and write numbered acceptance criteria for the ticker.
